# Code Availability

The FiNN/APidopnetwork MaHPIC E23 analysis code is prepared for
https://github.com/xsy2024/APidopnet (version 0.1.0).

The repository contains the experiment scripts, table-generation command,
dependency files, tests, and eight GEO expression workbooks. Run
`make release-check` to verify the package and `make reproduce` to generate
the E23 validation tables. The methods and output files are documented in
`docs/reproducibility.md`.
